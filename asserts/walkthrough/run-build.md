# Run the first build

**Run build** uploads the sources and the build list, runs the build on the IBM i and downloads the results.

The output appears in the panel **OBI Build**, and you can cancel a running build. Afterwards the build summary shows the result of each command, and compile errors appear in the **Problems** view.

In an editor, build the current source with `Ctrl+Alt+Shift+B`, or show its changes with `Ctrl+Alt+Shift+C` (macOS: `Cmd` instead of `Ctrl`).
