# Initialize an OBI project

Open the folder of your project, then run **Initialize**. It creates the `.obi` folder with the project configuration and a `.gitignore` for personal and generated files.

Existing files are not overwritten.

Your sources belong into `src/<library>/<source file>/<member>.<type>`, for example `src/mylib/qrpglesrc/hello.rpgle.pgm`.
